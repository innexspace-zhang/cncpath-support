# PRIVACY_POLICY（隐私政策草案）

Version（版本）: V1.4  
Status（状态）: Published（已发布）  
Last Update（最后更新）: 2026-08-09

---

# 1. Scope（适用范围）

This Privacy Policy describes how CNC Path handles information in the iPhone and iPad application.

本隐私政策说明 CNC Path 在 iPhone 和 iPad App 中如何处理信息。

CNC Path is an auxiliary CNC program workspace for local program management, editing, OCR import, instruction reference, and lightweight toolpath simulation.

CNC Path 是一款用于本地程序管理、编辑、OCR 导入、指令查询和轻量刀路仿真的辅助型 CNC 程序工作台。

---

# 2. Data Collection（数据收集）

The current release does not require an account and does not include advertising, analytics SDKs, tracking SDKs, or a CNC Path-operated cloud account or program-storage server.

当前版本不要求创建账户，也不包含广告、分析 SDK、跟踪 SDK，或由 CNC Path 运营的云端账号及程序存储服务器。

The current release does not transmit CNC programs, selected photos, recognized text, or usage data to a CNC Path server.

当前版本不会将 CNC 程序、所选照片、识别文本或使用数据传输到 CNC Path 服务器。

If these practices change in a future version, this policy and the App Store privacy disclosure must be updated before release.

如果未来版本改变上述处理方式，必须在发布前同步更新本政策和 App Store 隐私申报。

---

# 3. Camera, Photos, and OCR（相机、照片与 OCR）

CNC Path requests camera access only when the user chooses to capture a CNC program image.

只有当用户选择拍摄 CNC 程序图片时，CNC Path 才会请求相机权限。

CNC Path uses the system photo picker when the user chooses existing images.

当用户选择已有图片时，CNC Path 使用系统照片选择器。

OCR recognition uses Apple Vision on the device. Selected or captured images are processed locally and are not uploaded by the current release.

OCR 识别使用设备上的 Apple Vision。当前版本在本地处理所选或拍摄图片，不会上传图片。

Recognized CNC text may be saved to the local Program Library after recognition. Users must manually verify all OCR results.

识别出的 CNC 文本可能在识别后保存到本地程序库。用户必须人工核对所有 OCR 结果。

---

# 4. Local Storage（本地存储）

CNC Path stores program files, folders, editor state, simulation preferences, language, display units, and other app settings locally on the device.

CNC Path 会在设备本地保存程序文件、文件夹、编辑状态、仿真偏好、语言、显示单位及其他 App 设置。

Users can edit, export, move, or delete their program content through the application.

用户可以通过 App 编辑、导出、移动或删除自己的程序内容。

Deleting the app may remove locally stored CNC Path data unless the user has exported or backed up that data separately.

删除 App 可能会移除 CNC Path 的本地数据，除非用户已另行导出或备份。

---

# 5. Sharing and Export（分享与导出）

Users may explicitly create or restore a private Program Library backup through Apple iCloud. This optional feature uses the user's Apple account and the app's private iCloud container. CNC Path does not operate that service or require it for basic local use.

用户可以主动通过 Apple iCloud 创建或恢复程序库私有备份。该可选功能使用用户的 Apple 账户和 App 私有 iCloud 容器。CNC Path 不运营该服务，基础本地功能也不要求使用该服务。

Apple's terms and privacy practices apply to iCloud. Users may leave iCloud backup unused and can export files separately.

iCloud 适用 Apple 的条款与隐私规则。用户可以不使用 iCloud 备份，也可以另行导出文件。

CNC Path shares or exports content only after a user initiates an export or system Share action.

只有在用户主动执行导出或系统分享操作后，CNC Path 才会分享或导出内容。

The destination selected in the system share sheet may have its own privacy practices.

用户在系统分享面板中选择的目标服务可能适用其自身隐私规则。

---

# 6. Safety and Sensitive Content（安全与敏感内容）

CNC programs may contain confidential production information. Users should review files before exporting or sharing them.

CNC 程序可能包含保密的生产信息。用户应在导出或分享前检查文件内容。

CNC Path does not provide collision guarantees, machining safety guarantees, or complete real-machine verification.

CNC Path 不提供碰撞保证、加工安全保证或完整真实机床验证。

---

# 7. Children（儿童）

CNC Path is a professional and educational CNC utility and is not specifically directed to children.

CNC Path 是面向 CNC 专业与学习场景的工具，并非专门面向儿童。

---

本政策发生重大变化时，将更新政策内容，并在需要时同步更新 App Store 隐私申报。
