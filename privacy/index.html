隐私政策

Privacy Policy

最后更新 Last updated：2026-08-09

1. 适用范围 · Scope

本隐私政策说明 CNC Path 在 iPhone 和 iPad App 中如何处理信息。CNC Path 是一款用于本地程序管理、编辑、OCR 导入、指令查询和轻量刀路仿真的辅助型 CNC 程序工作台。

This Privacy Policy describes how CNC Path handles information in the iPhone and iPad application. CNC Path is an auxiliary CNC program workspace for local program management, editing, OCR import, instruction reference, and lightweight toolpath simulation.

2. 数据收集 · Data Collection

当前版本不要求创建账户，也不包含广告、分析 SDK、跟踪 SDK，或由 CNC Path 运营的云端账号及程序存储服务器。当前版本不会将 CNC 程序、所选照片、识别文本或使用数据传输到 CNC Path 服务器。

The current release requires no account and includes no advertising, analytics SDKs, tracking SDKs, or CNC Path-operated cloud account or program-storage server. It does not transmit CNC programs, selected photos, recognized text, or usage data to a CNC Path server.

如果未来版本改变上述处理方式，必须在发布前同步更新本政策和 App Store 隐私申报。

If these practices change in a future version, this policy and the App Store privacy disclosure must be updated before release.

3. 相机、照片与 OCR · Camera, Photos & OCR

只有当用户选择拍摄 CNC 程序图片时，CNC Path 才会请求相机权限。选择已有图片时，App 使用系统照片选择器。OCR 使用设备上的 Apple Vision；所选或拍摄图片在本地处理，当前版本不会上传图片。识别结果保存前必须由用户人工核对。

Camera access is requested only when the user captures a CNC program image. Existing images are selected with the system photo picker. OCR uses Apple Vision on-device; selected or captured images are processed locally and are not uploaded by the current release. Users must review recognized text before saving.

4. 本地存储 · Local Storage

CNC Path 在设备本地保存程序文件、文件夹、编辑状态、仿真偏好、语言、显示单位及其他 App 设置。用户可以通过 App 编辑、导出、移动或删除自己的程序内容。删除 App 可能会移除本地数据，除非用户已另行导出或备份。

CNC Path stores program files, folders, editor state, simulation preferences, language, display units, and other app settings locally. Users can edit, export, move, or delete their content. Deleting the app may remove local data unless it has been exported or backed up separately.

5. iCloud、分享与导出 · iCloud, Sharing & Export

用户可以主动通过 Apple iCloud 创建或恢复程序库私有备份。该可选功能使用用户的 Apple 账户和 App 私有 iCloud 容器。CNC Path 不运营该服务，基础本地功能也不要求使用该服务。iCloud 适用 Apple 的条款与隐私规则。

Users may explicitly create or restore a private Program Library backup through Apple iCloud. This optional feature uses the user's Apple account and the app's private iCloud container. CNC Path does not operate that service or require it for basic local use. Apple's terms and privacy practices apply to iCloud.

只有在用户主动执行导出或系统分享操作后，CNC Path 才会分享内容。系统分享面板中选择的目标服务可能适用其自身隐私规则。

CNC Path shares content only after the user initiates an export or system Share action. A destination selected in the system share sheet may have its own privacy practices.

6. 安全与敏感内容 · Safety & Sensitive Content

CNC 程序可能包含保密生产信息，用户应在导出或分享前检查文件内容。CNC Path 不提供碰撞保证、加工安全保证或完整真实机床验证。

CNC programs may contain confidential production information. Users should review files before exporting or sharing. CNC Path does not guarantee collision detection, machining safety, or complete real-machine verification.

7. 儿童 · Children

CNC Path 是面向 CNC 专业与学习场景的工具，并非专门面向儿童。

CNC Path is a professional and educational CNC utility and is not specifically directed to children.

8. 政策变更 · Changes

本政策发生重大变化时，将更新政策内容，并在需要时同步更新 App Store 隐私申报。

Material changes to this policy will be reflected in an updated policy and, where required, in the App Store privacy disclosure.

9. 联系我们 · Contact

如有隐私或支持问题，请发送邮件至 innexspace@icloud.com。

For privacy or support questions, email innexspace@icloud.com.
